# Go project Order-flow

## Stack: Kafka, Go, Docker, PostgreSQL, Redis

### Description
This project is a simple order flow system built using Go, Kafka, Docker, PostgreSQL, and Redis. It demonstrates how to handle order processing in a distributed system using message queues and caching.

### STARTING INSTRUCTIONS
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd order-flow
   ```
2. Build the Docker images:
   ```bash
   docker-compose build
   ```
3. Start the services:
    ```bash
    docker-compose up
    ```
